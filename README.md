## About
I’m a data scientist and machine learning engineer working across enterprise analytics, data engineering, applied machine learning, and Graph ML research.

I’m currently working more with Apache Superset and early-stage AI-agent and MCP workflows, while continuing research around graph representation learning and anomaly detection.
